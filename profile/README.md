### Endless boss practice for souls-likes

Neither you nor the boss can die. Keep fighting, learn the moveset, and watch every attempt get
logged so you can see yourself improve.

**[Website](https://git-gud-gym.github.io/)** · **[Download](https://github.com/Git-Gud-Gym/launcher/releases/latest)** · **[Docs](https://git-gud-gym.github.io/docs)** · **[Request a game](https://github.com/Git-Gud-Gym/registry/issues/new?template=game_request.yml)**

</div>

| Repository | What it is |
|---|---|
| [**launcher**](https://github.com/Git-Gud-Gym/launcher) | The Git Gud Gym desktop app: game library, live stats, overlay |
| [**sdk**](https://github.com/Git-Gud-Gym/sdk) | Trainer core and `GameAdapter` interface that every game module is built on |
| [**module-eldenring**](https://github.com/Git-Gud-Gym/module-eldenring) | Elden Ring support |
| [**registry**](https://github.com/Git-Gud-Gym/registry) | The reviewed list of game modules, published as the app's `catalog.json` |
| [**git-gud-gym.github.io**](https://github.com/Git-Gud-Gym/git-gud-gym.github.io) | The website and docs |

**Want your game supported?** Each game is a small module built on the
[SDK](https://github.com/Git-Gud-Gym/sdk). See
[Adding a game](https://github.com/Git-Gud-Gym/sdk/blob/main/docs/ADDING_A_GAME.md).

<sub>Offline, single-player practice only. Not affiliated with any game publisher.</sub>
